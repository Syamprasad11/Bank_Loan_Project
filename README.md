# Bank Loan Lending Analysis

## Project Overview
This project focuses on analyzing bank loan data to evaluate lending performance, borrower characteristics, repayment patterns, and credit risk. Using Python, SQL (MySQL), and Power BI, this project transforms raw loan data into meaningful insights to support better financial decision-making.

## Business Problem
Financial institutions need to understand loan repayment behavior and identify potential credit risks to make informed lending decisions. This project analyzes historical loan data to identify repayment patterns, evaluate borrower profiles, and understand factors associated with loan defaults.

## Project Objectives
- Analyze overall loan performance and repayment trends.
- Identify patterns associated with loan defaults.
- Evaluate borrower profiles based on annual income, credit grades, and loan characteristics.
- Analyze loan distribution across different categories.
- Identify potential credit risk indicators.
- Develop an interactive Power BI dashboard for data-driven insights.

## Technologies Used
- **Python:** Data cleaning, preprocessing, feature engineering, and exploratory data analysis.
- **SQL (MySQL):** Data querying, aggregation, and credit risk analysis.
- **Power BI:** Interactive dashboards, KPI tracking, and data visualization.
- **Python Libraries:** Pandas, NumPy, Matplotlib, Seaborn, SQLAlchemy.

## Dataset Description
The project uses a bank loan dataset containing 38,576 loan records with borrower and loan-related information.

Key attributes include:
- Loan Amount
- Annual Income
- Loan Status
- Interest Rate
- Credit Grade and Subgrade
- Home Ownership
- Employment Length
- Total Credit Accounts
- Loan Term
- Purpose of Loan

## Project Workflow

### 1. Data Cleaning and Preparation (Python)
- Inspected the dataset for missing values and duplicate records.
- Checked data types and inconsistencies.
- Performed data cleaning and preprocessing.
- Created additional features for better analysis.
- Prepared the dataset for further analysis.

### 2. Exploratory Data Analysis (Python)
- Analyzed loan distribution and repayment patterns.
- Evaluated borrower income categories.
- Examined loan status across different credit grades.
- Investigated relationships between borrower characteristics and loan outcomes.
- Created visualizations to identify important trends and patterns.

### 3. SQL Analysis (MySQL)
- Connected Python with MySQL using SQLAlchemy.
- Imported and queried the cleaned dataset.
- Performed aggregations and data filtering.
- Analyzed loan performance across different categories.
- Evaluated charge-off rates and repayment trends.
- Investigated credit risk patterns using SQL queries.

### 4. Power BI Dashboard
- Developed interactive dashboards to analyze loan performance.
- Created key performance indicators (KPIs).
- Visualized loan applications, funded amounts, and repayment performance.
- Analyzed good loans and bad loans.
- Explored lending trends across borrower and loan categories.

## Key Findings
- Analyzed **38,576 loan records**.
- Approximately **83.33% of loans were fully paid**.
- Approximately **13.82% of loans were charged off**.
- Evaluated loan repayment patterns across different credit grades.
- Identified borrower and loan characteristics associated with credit risk.
